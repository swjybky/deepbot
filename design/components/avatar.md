# 头像 BotAvatar / UserAvatar

> 何时读：显示 Bot 或用户。
> 代码：[`BotAvatar.tsx`](../../apps/desktop/ui/components/BotAvatar.tsx)、[`UserAvatar.tsx`](../../apps/desktop/ui/components/UserAvatar.tsx)、形状与调色板 [`theme/avatar.ts`](../../apps/desktop/ui/theme/avatar.ts)

## BotAvatar：鲨鱼头像

每个 Bot 的头像 = 3D 果冻质感的身体形状 + 同色背鳍 + 两只微微发光的白色竖胶囊眼睛（卡通风格，宽 5、高 9 网格单位，宽高 1:1.8，不画眼白和瞳孔；用户从 1:2.4 / 1:1.8 / 1:1.5 / 1:1.2 / 圆形中选定 1:1.8 并放大一圈），没有嘴，由 `shape`（13 种）和 `color`（11 色）决定，用 Canvas 绘制。

```tsx
<BotAvatar shape={bot.shape} color={bot.color} size={36} />
```

| 尺寸 | 位置 |
|---|---|
| 30 | 对话区顶部 Bot 胶囊 |
| 40 | 形状选择项 |
| 42 | 侧栏 Bot 行 |
| 64 | 侧栏置顶 Bot（右下角 18pt 星标徽章：`bg-pin`，2pt 白边） |
| 84 | Bot 信息面板 |
| 120 | 创建新 Bot 的预览 |

形状（形状网格按此顺序）：果冻 `jelly`（排第一个，宽大于高的扁圆方块，鳍更大、偏右；保持扁圆，不要拉成竖长）、圆鲨 `circle`、鱼雷 `torpedo`、方鲨 `squircle`、礁石 `block`、浪花 `cloud`、珊瑚 `flower`、水滴 `drop`、鲸豆 `bean`、六角 `hex`、胶囊 `pill`、贝壳 `pentagon`、深潜 `wave`。

创建新 Bot 默认选择 `jelly`；已有 Bot 保留自己的形状。眼睛比例、果冻轮廓与身体质感按已选定规格维护，不随页面布局调整一并重画。

调色板（`botColors`）：黑 `#141414`、棕 `#A0673A`、红 `#F0283C`、橙 `#F26A1B`、琥珀 `#F5A00E`、绿 `#1DB863`、青 `#14B3A0`、蓝 `#2183F2`、紫 `#8B5CF6`、粉 `#EC3C8E`、灰 `#9A9A9A`。

规则：

- Bot 的颜色**只能**取自 `botColors`；它同时是打开该 Bot 时的强调色（[tokens.md](../tokens.md#强调色)）。
- 头像不加圆形底、描边或阴影——形状本身就是轮廓。
- 3D 质感全部画在身体之内（`source-atop`），光源在左上：先整体提成近白，再用略偏右下、轻微模糊的身体轮廓影子以本色盖回，只留左上一道亮边；再整体提亮成半透明外壳，用大幅模糊的轮廓影子以加深加饱和的本色（`deepen`）填回中间，所以中心深、边缘透亮；最后叠中心加深、左上柔光和底边透光。轮廓影子都是路径画在画布外、只让影子落回。不要沿路径描边做亮边——形状由多个重叠子路径拼成，描边会画出内部接缝。光源固定在左上，不随形状旋转。
- 眼睛中心在网格 y=23.8（加上整体下移 2.5），两眼中心距 12.4，各形状共用；改眼睛大小或位置后，要在九个注视方向（正视、上下左右、四个斜角）下检查水滴、珊瑚、贝壳等窄形状里眼睛仍完整。
- 身体按 1 倍铺满 48 画布（下移 2.5，鳍尖 0.5）。六角、贝壳的圆角描边只描 `body`（不含背鳍），否则背鳍被加粗后会顶出画布被削平。改形状后按 [verify 技能](../../skills/verify/SKILL.md)验证：`check run --scope ui` 跑头像回归，聊天和侧栏里的头像用 `ui run <场景> --target native` 截图核对。[AvatarFixture.tsx](../../apps/desktop/AvatarFixture.tsx) 列出全部形状、颜色和尺寸。CLI 目前取不到这张全形状原生总览图，需要时按技能「CLI 做不到时」处理，并提议加入 CLI。
- 新形状加在 `avatarShapes` 里（48×48 网格，背鳍自动拼接，也可传入自己的背鳍），并给中文名。
- 头像是装饰：外层按钮负责 `accessibilityLabel`（"打开 小菜"）。
- 眼睛跟随鼠标：只有鼠标在某个头像背后的背景区域（侧栏行、置顶格、形状格、Bot 胶囊）内时，这个头像的眼睛才朝鼠标转（从头像边缘起转到最大），其它头像保持正视；眼睛始终滑向目标、不跳变：进入区域和移动时约 0.3 秒跟上鼠标，离开区域后约 1 秒回正，都由临界阻尼弹簧（`glide`）驱动，起步平缓、不过冲。不要让眼睛一帧跳到位，也不要只给回正加动画——进入相邻区域时新头像眼睛瞬跳，看起来就像“回得太快”。减少动态效果时立即到位。没有背景的头像（信息面板、创建预览）以头像自身为区域。转向一侧时两眼间距收窄、远侧眼睛变窄，做出立体转头感。区域由 `avatarHover()` 创建：把 `hover.handlers` 展开在背景所在的 View 上（`Button` 不收鼠标事件，挂在包住它的 View 上），再把 `hover` 传给 `<BotAvatar hover={hover} />`；不传则头像自己监听。不要改回全窗口共享的鼠标位置。

## UserAvatar：用户首字母

圆形 + 名字首字母（大写，semibold，`icon-foreground`）。34（侧栏，`bg-edge`）或 44（设置账户卡，`bg-chip` + `border-edge`）。
有真实头像图片后在这个组件里加 `Image` 分支，调用方不变。
