# DeepBot 验证资料索引

执行规则见 [verify 技能](../skills/verify/SKILL.md)，新验证复制 [报告模板](_template/report.md)。所有验证报告、截图、日志、对比结论和业务产物集中在本目录。测试源码继续由现有模块目录管理。

Git 中保留索引、模板和验证报告。报告引用的原始截图、日志、快照、录屏和归档辅助文件存放在本机对应目录，新的克隆需要按报告中的步骤重跑以获取证据。

```text
test/
  README.md                          # 功能/时间索引
  _template/report.md                # 本次验证记录模板
  <功能>/<YYYY-MM-DD>/<HHmmss-主题>/
    report.md                        # 前置、步骤、预期、实际、结论
    logs/                            # 命令输出与退出码
    screenshots/                     # 修改前/后、参照和关键状态原图
    artifacts/                       # 脱敏业务产物和结构化结果
```

迁入的历史目录不补造执行时间，保留原目录内部结构。日期按报告正文或文件本机修改日期归档；未确认的实际执行时间不据此推断。以下历史结论未在迁移时重跑，不能证明当前代码通过。
