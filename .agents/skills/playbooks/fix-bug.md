# 修 bug

用于修复已发生的行为缺陷。

1. 在[功能地图](../../../references/features/README.md)找到命中的功能页，读用户路径、CLI 命令和注意事项。涉及界面时，按 [DESIGN.md](../../../DESIGN.md) 的「按需加载约束」读相关主题。完成标准：说得出真实入口、可用场景和适用的设计条目。
2. 从报告的真实入口用 [verify CLI](../../../skills/verify/SKILL.md) 复现，留下最小输入和失败证据，例如截图、接口 JSON 或日志。
3. 查功能地图和代码，说明根因。查同一根因的其它入口，优先修共享逻辑。
4. 修复后重启实例，重跑原场景和同根因场景，证明已修好。
5. 按 ccs-mode 的[错误变规则](../ccs-mode/SKILL.md#错误变规则)选防复发手段。把可复用的定位依据补进功能页的注意事项。
6. 运行 `pnpm --silent verify check`，交付复现证据、修复后证据和检查结果。
