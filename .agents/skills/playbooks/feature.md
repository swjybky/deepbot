# 做功能

用于新增功能或改变现有行为。

1. 用户要求时，用大白话复述需求。从[功能地图](../../../references/features/README.md)确认界面入口、后端契约、已有数据和影响范围。涉及界面时，按 [DESIGN.md](../../../DESIGN.md) 的「按需加载约束」读相关主题。
2. 实现前写下用户能观察的成功条件，覆盖当前需求涉及的进入、操作、失败和保存后读取等状态。
3. 尽量复用现有组件和协议。
4. 用 [verify CLI](../../../skills/verify/SKILL.md) 操作真实入口并截图，对照设计条目看图，用 `api snapshot` 核对后端状态，回归受影响的功能。
5. 把新入口、新场景和新发现的坑更新到功能地图。
6. 运行 `pnpm --silent verify check`，交付截图、接口返回和检查结果。
